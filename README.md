# EnchantingEyes: 仿生眼实时视线模仿系统

> 致力于探索机器人非语言交互（Non-verbal HRI）中的拟人化视线控制技术。
> 

## 📖 项目简介

**EnchantingEyes** 是一个融合了计算机视觉（Computer Vision）与机器人控制（Robotics Control）的实验性项目。该项目旨在验证“从视频输入到机械执行”的端到端视线模仿链路。

通过实时捕捉视频流中人眼的细微动作（注视方向、眼球转动），系统利用运动学映射算法，驱动仿生机械眼结构做出同步的响应。该项目不仅是一个技术验证原型，也为社交机器人（Social Robots）的情感计算和拟人化交互提供了低成本的解决方案。

---

## 💡 背景与动机

在人机交互（HRI）领域，眼神交流（Eye Contact）是建立信任和传达意图的关键信号。传统的机器人眼部控制通常基于预设的脚本或简单的随机运动，往往显得呆板且缺乏“生命感”。

**EnchantingEyes** 试图解决以下问题：

- **如何低成本地捕捉高精度的人眼视线数据？**
- **如何将二维屏幕上的瞳孔运动，自然地映射为三维机械结构的舵机角度？**
- **如何通过算法消除机械运动的抖动，模拟生物眼球的“平滑追踪”特性？**

---

## 🌟 核心特性

- **无标记实时追踪 (Markerless Tracking)：** 基于 Google MediaPipe Face Mesh 深度学习模型，无需佩戴任何传感器，仅凭普通摄像头即可提取 468 个面部关键点，精准定位虹膜中心。
- **仿生运动学映射 (Biomimetic Mapping)：** 摒弃简单的线性转换，采用动态范围适配算法，将人眼的相对位移转化为机械眼球（2-DOF）的 Pitch（俯仰）和 Yaw（偏航）角度。
- **运动平滑处理 (Motion Smoothing)：** 内置平滑滤波算法（如卡尔曼滤波或移动平均），有效滤除视觉检测噪声，模拟生物眼球在注视移动物体时的平滑特性。
- **硬件解耦设计 (Hardware Agnostic)：** 核心逻辑层与驱动层分离，视觉结算模块通过标准串口协议（Serial Protocol）输出控制信号，可适配 Arduino、STM32 或 ESP32 等多种下位机。

## 🏗️ 系统架构

本项目采用经典的三层架构设计，实现了从感知到执行的闭环控制。

代码段

`graph LR
    A[视觉感知层] -->|原始坐标| B[核心逻辑层]
    B -->|控制指令| C[硬件执行层]
    
    subgraph A [视觉感知 / Perception]
    A1[视频流输入]
    A2[MediaPipe Face Mesh]
    A3[虹膜关键点提取]
    end
    
    subgraph B [核心逻辑 / Logic]
    B1[坐标归一化]
    B2[矢量映射计算]
    B3[防抖与平滑滤波]
    end
    
    subgraph C [硬件执行 / Actuation]
    C1[串口通讯]
    C2[MCU控制器]
    C3[PWM舵机驱动]
    end`

### 1. 视觉感知层 (Perception Layer)

系统首先对视频流进行预处理，利用 MediaPipe 提取面部网格。通过计算瞳孔中心点相对于眼眶（Eye Contour）边缘的相对位置，输出标准化的二维向量 $(x, y)$，取值范围通常在 $[0, 1]$ 之间。

### 2. 核心逻辑层 (Logic Layer)

这是系统的“大脑”。它负责将归一化的二维向量转换为机械结构的物理角度。

- **映射公式：** 根据机械眼球的物理限位（例如左右各转动 $30^{\circ}$），将视觉信号重新映射。
- **滤波处理：** 对连续帧的数据进行加权平均，消除检测抖动，确保机械动作的连贯性。

### 3. 硬件执行层 (Actuation Layer)

下位机（如 Arduino）接收来自逻辑层的角度指令包（例如 `<P:90, Y:45>`），将其解析为 PWM 脉宽信号，驱动双轴舵机云台完成最终的物理动作。

## 🔬 应用场景

虽然 **EnchantingEyes** 处于验证阶段，但其技术路径可广泛应用于：

- **仿生机器人 (Animatronics)：** 影视特效或主题乐园中的高逼真机器人角色。
- **远程临场 (Telepresence)：** 让远程替身机器人实时复刻操作者的眼神，增强临场感。
- **辅助医疗：** 帮助眼动障碍患者通过眼球运动控制外部设备。
- **交互艺术装置：** 能够与观众进行眼神跟随互动的艺术作品。

## 📅 项目规划 (Roadmap)

- [ ]  **阶段一：** 完成基于 MediaPipe 的视线捕捉与基础舵机映射。
- [ ]  **阶段二：** 引入眼睑（Eyelid）协同控制，模拟眨眼与表情配合。
- [ ]  **阶段三：** 优化“扫视”（Saccade）算法，模拟人眼快速切换焦点时的非线性速度曲线。
- [ ]  **阶段四：** 双眼视差校正，实现更逼真的双目聚焦效果。
